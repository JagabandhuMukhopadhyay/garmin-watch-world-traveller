# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Garmin Connect IQ **watch app** (`type="watch-app"`, not a watch face: watch faces cannot use the START/UP/DOWN buttons or menus) written in Monkey C, targeting the Forerunner 965 (`fr965`), min API level 4.2.0. A multi-flight travel companion: a ring of cities (Origin > Change 1 > [Change 2 >] Destination; one or two plane changes), each with local time, boarding (BRD) and reach (RCH) times, and flown/remaining meters for the flight. Not a git repository.

## Build / run

There is no CLI build script or test suite. Everything goes through the Monkey C VS Code extension (Connect IQ SDK required):

- Build: command palette → `Monkey C: Build Current Project` (output: `bin/JagaGarmin1.prg`)
- Run in simulator: `Monkey C: Run` / F5 (uses the Connect IQ simulator)
- Signing key: `bin/developer_key`
- The VS Code language server reports Monkey C compile errors as diagnostics, which is the quickest check when no simulator is available.

`bin/`, `gen/`, `mir/`, `internal-mir/` and the root-level `JagaGarmin1.prg*` are build output; don't edit them.

## Architecture

- [monkey.jungle](monkey.jungle) only points at [manifest.xml](manifest.xml). The manifest is generated by the extension (header says don't hand-edit); prefer the `Monkey C: Edit ...` commands.
- [source/Stops.mc](source/Stops.mc): `Stops` module. Four city slots (0 Origin, 1 Change 1, 2 Change 2, 3 Destination) with property keys per slot (label, offset, boarding, flight minutes), `activeSlots()` (`[0,1,3]` or `[0,1,2,3]` from the `PlaneChanges` setting), `tagFor()` (START/CH1/CH2/DEST tag from position), `moveFocus()`, the time-zone list and shared helpers. The view and menus read keys from here; the view shows three blocks at a time whatever the number of cities.
- [source/JagaGarmin1View.mc](source/JagaGarmin1View.mc): `WatchUi.View` that draws everything by hand in `onUpdate`; a 10 s `Timer` triggers redraws. Focus stop in the middle (large time, BRD/RCH line, Flown/Remaining rings), previous/next stops above/below. Font pair is chosen by measuring `getFontHeight` so three blocks fit the round screen. Each stop's time = `Time.now()` + UTC offset (minutes), read back with `Gregorian.utcInfo`; Origin uses the watch's own zone. Boarding is stored as `YYYY-MM-DD HH:MM` in the airport's local time; if empty (or no flight time) no BRD / RCH is shown for that city. Each city also has an IATA `<Key>Code` (menu: Airport ID) shown as `Name (CODE)`; [source/Airports.mc](source/Airports.mc) looks codes up in `resources/strings/airports.xml` (one string per first letter, generated from OurAirports data) and fills in the city name
- [source/JagaGarmin1Delegate.mc](source/JagaGarmin1Delegate.mc): button map. START (`onSelect`) opens the focus stop's menu, DOWN/UP (`onNextPage`/`onPreviousPage`) move the focus around the ring (stored in property `FocusIndex`).
- [source/StopMenu.mc](source/StopMenu.mc): START menu (`Menu2`): time zone list, airport name (`TextPicker`), boarding time and flight time (`Picker`s), start/stop flight. "Start flight" saves the UTC start time in `Application.Storage` (`FlightStart<stop>`); the rings count from it (0 flown before it is started).
- [source/Alarms.mc](source/Alarms.mc): boarding alarms (`(:background)` module + `AlarmServiceDelegate`). Each city except the destination has `<Key>AlarmMin` (minutes before its *entered* boarding time; placeholders never alarm). While the app is open the view checks every second and vibrates/beeps/shows a banner; when closed, `Alarms.schedule()` registers a one-shot background event for the next alarm and the system shows a wake prompt. Needs the `Background` permission in the manifest. `Stops` is also `(:background)`, so keep it free of `Rez` and view code.
- [source/FieldPicker.mc](source/FieldPicker.mc): custom one-screen multi-field picker used by the START menu (the stock Garmin pickers show one column per screen on the fr965). The airport name uses the stock `WatchUi.TextPicker`, which on a real fr965 is Garmin's abc/def keyboard.
- Settings also live in `resources/settings/` (`properties.xml` defaults, `settings.xml` phone UI, titles in `strings/strings.xml`), and the on-watch menus write the same properties, so either side can edit. Flight length per leg is in minutes (`StartFlightMin`, `Change1FlightMin`).
- `resources/layouts/layout.xml` is left over from the template and is unused.
- Product spec: [JM-Garmin-v1.md](JM-Garmin-v1.md) (written for the original watch-face idea; the code has moved on).
- The app name shown in the watch's START-button list is the `AppName` string ("World Traveller").
- `Rez.*` is generated from the resources at build time (`gen/`); new strings or drawables must be declared in `resources/` to appear there.
